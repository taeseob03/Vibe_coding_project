# 팀 캐릭터 상세 사양 (초안)

원격 main에 추가된 팀 제안을 원본 계획과 분리해 보관합니다.
현재 동작 규칙은 api-contract.md와 B 서버 계산을 기준으로 합니다.
7.1의 프로필과 7.2의 픽셀 외형·학과 과잠은 통합했습니다. 아래 역할/레벨/소품 단계 제안은
현재 구현을 덮어쓰는 확정 규칙이 아닙니다. 특히 스탯 계산은 사용자 지정대로 B가 담당합니다.

## 7. 서비스 상세 사양

이 장은 위 계획의 기능에 실제 입력 항목과 규칙을 더한 것이다. 위 내용과 다르면 이 장을 따른다. 표시된 **초안** 항목은 구현 전에 A·B가 확정한다.

### 7.1 최초 설정 (A 담당)

최초 설정은 두 화면으로 나눈다. 첫 화면을 저장하면 다음 화면으로 넘어가고, 중간에 종료해도 저장된 단계부터 이어간다.

**① 프로필 입력**

| 항목 | 키 | 형식 | 규칙 (초안) |
|---|---|---|---|
| 닉네임 | `nickname` | 문자열 | 2~12자, 필수 |
| 학년 | `grade` | 정수 | 1~4 중 선택, 필수 (초과학기·대학원 포함 여부는 확정 필요) |
| 학과 | `major` | 선택 | `embedded`(임베디드시스템공학과), `computer`(컴퓨터공학과), `ict`(정보통신공학과) 중 하나, 필수 |

**② 캐릭터 선택·커스터마이즈**

| 항목 | 키 | 선택지 (초안) |
|---|---|---|
| 기본 캐릭터 | `base` | `male`(기본 남성), `female`(기본 여성) |
| 머리 길이 | `hair_length` | `short`, `medium`, `long` |
| 머리 색 | `hair_color` | `black`, `brown`, `blonde`, `red`, `blue`, `pink` 등 정해진 팔레트 |

- 머리 색은 자유 색상 입력이 아니라 정해진 팔레트로 받는다. 픽셀 이미지의 명암 색을 팔레트별로 맞추기 위해서다.
- 미리보기는 선택 즉시 갱신한다. 저장 시 캐릭터가 생성되고 메인으로 이동한다.
- 설정 상태 예시: `setup_step`: `profile` → `character` → `done`.

```json
{
  "profile": { "nickname": "새내기", "grade": 1, "major": "computer" },
  "appearance": { "base": "female", "hair_length": "long", "hair_color": "black" },
  "setup_step": "done"
}
```

### 7.2 캐릭터 그림 형식 (B 담당, ⑦ 디자인 단계에서 완성)

- 레퍼런스는 **2~2.5등신 치비 비율의 픽셀아트 캐릭터**이다. 큰 머리, 큰 눈, 작은 몸, 검은 외곽선, 정면을 살짝 비낀 서 있는 자세를 따른다.
- 레퍼런스 이미지는 비율과 화풍 참고용이다. 기존 게임의 스프라이트나 기존 작품 캐릭터를 그대로 쓰거나 따라 그리지 않고, 팀이 직접 그린 원본 이미지를 사용한다.
- 기준 캔버스 (초안): 캐릭터 64×96px, 화면에서는 3~4배 정수 배율로 확대 (`pixelArt: true`로 흐림 방지).
- 기준점: 발 중앙. 모든 레이어는 같은 캔버스 크기와 기준점을 공유한다.
- 레이어 순서 (아래 → 위):
  1. 뒷머리 (`hair_back_{length}`)
  2. 몸체·옷 (`body_{base}`)
  3. 얼굴 (`face_{base}`)
  4. 앞머리 (`hair_front_{length}`)
  5. 카테고리 소품 (7.4)
- **옷은 학과 과잠으로 고정한다.** 학과를 고르면 자동으로 입혀지고, 기본 남성·여성 모두 같은 과잠을 입는다 (하의만 다름).

  | 학과 | 과잠 |
  |---|---|
  | 임베디드시스템공학과 `embedded` | 하늘색 몸판 + 흰 소매 + 남색 시보리 |
  | 컴퓨터공학과 `computer` | 임베디드 디자인의 검정 버전 (검정 몸판 + 흰 소매) |
  | 정보통신공학과 `ict` | 회색 |

- 과잠 레이어 이름: `jacket_{major}` (몸체 레이어 위, 얼굴 아래).
- 머리 색은 머리 레이어를 회색조로 그리고 팔레트 색을 입히거나, 색별 이미지를 따로 만든다. 방식은 첫 시안에서 결정한다.

### 7.3 기록 분류 (B 담당)

AI는 기록 하나를 아래 네 카테고리 중 **하나**로 분류한다.

| 카테고리 | 키 | 예시 |
|---|---|---|
| 술 | `drink` | 동기들과 술자리, MT 뒤풀이 |
| 공부 | `study` | 도서관 공부, 과제, 시험 |
| 운동 | `exercise` | 헬스, 러닝, 동아리 축구 |
| 연애 | `love` | 데이트, 소개팅, 고백 |
| 해당 없음 | `none` | 네 카테고리와 관련 없는 기록. 레벨이 오르지 않는다 |

- 기존 `study`, `social`, `exercise`, `culture`, `daily` 분류를 위 다섯 값으로 교체한다 (`analysis/schemas.py`, `docs/api-contract.md`, 예제 JSON, 테스트 함께 수정).
- 기록 하나가 여러 카테고리에 걸치면 가장 중심이 되는 하나만 고른다. (여러 개 동시 인정은 이후 검토)
- AI는 분류·키워드·요약만 반환하고, 레벨 상승은 서버 규칙(A)이 결정한다.

### 7.4 레벨과 소품 규칙 (A: 계산·저장, B: 표시)

- 카테고리별로 레벨을 따로 가진다. 시작 레벨은 0이다.
- 분석이 완료된 기록 하나가 해당 카테고리 레벨을 **+1** 올린다. `none`은 올리지 않는다.
- 같은 기록으로는 한 번만 오른다 (재시도·중복 요청에도 기록 ID 기준으로 1회).
- 소품 단계 `tier = floor(level / 5)`. 5레벨마다 단계가 오른다.

| 카테고리 | 소품 | 표시 위치 (초안) |
|---|---|---|
| 술 `drink` | 술병 | 캐릭터 왼쪽 바닥 |
| 공부 `study` | 책 | 캐릭터 오른쪽 바닥 |
| 운동 `exercise` | 덤벨 | 캐릭터 왼쪽 위 |
| 연애 `love` | 하트 | 캐릭터 머리 위·오른쪽 위 |

**단계별 표시 (초안)**

| 레벨 | 단계 | 소품 개수 | 크기 배율 |
|---|---|---|---|
| 0~4 | 0 | 0 (표시 안 함) | - |
| 5~9 | 1 | 1 | 1.0 |
| 10~14 | 2 | 2 | 1.15 |
| 15~19 | 3 | 3 | 1.3 |
| 20 이상 | 4+ | 3 (최대) | 단계마다 +0.15, 최대 1.6 |

- 개수는 최대 3개로 제한해 네 카테고리 소품이 동시에 있어도 캐릭터를 가리지 않게 한다.
- 단계가 오를 때는 화면에서 소품이 커지며 나타나는 짧은 연출을 보여준다.
- 서버는 레벨만 저장하고, 개수·크기는 위 표에 따라 화면에서 계산한다. 응답에 `tier`를 함께 내려 계산 기준을 한쪽에 둔다.

```json
{
  "levels": [
    { "category": "drink",    "level": 3,  "tier": 0 },
    { "category": "study",    "level": 12, "tier": 2 },
    { "category": "exercise", "level": 5,  "tier": 1 },
    { "category": "love",     "level": 0,  "tier": 0 }
  ]
}
```

### 7.5 이 장으로 바뀌는 연결 규약

| 항목 | 기존 | 변경 |
|---|---|---|
| 활동 분류 | `study`, `social`, `exercise`, `culture`, `daily` | `drink`, `study`, `exercise`, `love`, `none` |
| 효과 대응 | `study → book`, `social → heart` | 카테고리별 레벨 +1, 소품은 레벨에서 계산 |
| 효과 반영 결과 | `effects: [{effect_id, level, visible}]` | `levels: [{category, level, tier}]` + 이번 기록으로 오른 카테고리 |
| 최초 설정 | 닉네임·외형 | 닉네임·학년·학과(3개 중 선택) → 기본 캐릭터·머리 길이·머리 색, 옷은 학과 과잠 |

### 7.6 확정이 필요한 항목

- 학년 범위 (1~4만인지, 초과학기·대학원 포함인지)
- 머리 길이·색의 최종 선택지 개수
- 20레벨 이후 상한 (레벨 상한을 둘지, 크기만 계속 키울지)
- 같은 날 같은 카테고리 기록을 여러 번 올렸을 때 모두 +1 할지 (하루 상한 여부)
