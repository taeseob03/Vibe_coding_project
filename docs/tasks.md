## 선택 확장

- 고급 캐릭터/배경 자산 교체와 연출 조정
- 기록 수정·삭제 및 스탯 재계산/회수 정책
- 여러 서버를 위한 공유 작업 큐와 방 상태 저장
- 서비스용 계정 소유 확인과 계정 복구

사용자가 이번 통합 작업 전체와 pull/push·main 반영·서버 실행을 맡겼습니다.
현재 실행은 단일 프로세스 로컬 서버이며 공개 운영 환경으로의 배포와는 구분합니다.
