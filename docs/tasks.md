# 개발 진행 상황

제공받은 원문은 루트의 개발 계획에 보존합니다. 최신 역할 결정은 이 문서와 API 규약에 반영합니다.

## 역할

- A: 계정·캐릭터, 사용자별 저장·조회, 공통 DB와 통합 API
- B: 사진/글 Gemini 분석, 키워드/활동 추출, 스탯 변화·상태 계산
- C: 게임 화면·캐릭터 디자인·표정·애니메이션

## 완료

- [x] 역할별 초기 환경·Git 브랜치·CI·마이그레이션
- [x] 아이디 접속·세션 유지·로그아웃
- [x] 닉네임/색상 최초 설정·임시 저장·복원·캐릭터 1개 제약
- [x] A의 초기 소품 강화 실험 구현과 테스트 (현재는 호환용)
- [x] B 원본 브랜치 merge 및 계산 규칙 재사용
- [x] 로그인 계정에 사진/글·분석 결과·스탯 연결
- [x] pending/processing/completed/failed 조회·실패 재시도
- [x] 분석 실패/상태 저장 실패 구분·저장된 분석으로 상태 재처리
- [x] 계정별 목록/상세/사진/재시도 접근 권한
- [x] 동일 요청/동시 처리 중복 방지·서버 재시작 후 명시적 재시도
- [x] C가 사용할 API 문서와 기능 확인 화면

## 남은 검증·후속 단계

- [ ] 유효한 Gemini 키/모델로 실제 사진 분석 품질·접근 권한 확인
- [ ] C의 실제 게임 화면·캐릭터 자산 통합
- [ ] B의 구체적인 표정/상태 코드가 추가되면 C 표현과 연결
- [ ] 여러 서버에서 사용할 작업 큐·작업 소유권 확장
- [ ] 기록 수정/삭제와 상태 재계산 규칙 합의
- [ ] 칭호
- [ ] 라운지

각 단계는 사용자 요청 시에만 시작합니다. 자동 검증은 Gemini 응답을 대체하며 실제 외부 API를 호출하지 않습니다.
