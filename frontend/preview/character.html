글을 올리면 술·공부·운동·연애 중 하나로 분류되고 해당 레벨이 +1 돼요. 5레벨마다 소품이 생기고, 개수와 크기가 커져요.

분류 결과가 여기에 표시돼요.
카테고리레벨소품테스트

    · 옷은 학과 과잠이에요: 임베디드 = 하늘색, 컴퓨터 = 검정(임베디드 디자인), 정보통신 = 회색.
    · 캐릭터는 계획서 7.2 형식(2~2.5등신 치비 픽셀, 레이어: 뒷머리 → 몸·옷 → 얼굴 → 앞머리 → 소품)으로 코드로 그린 임시 시안이에요. 최종 원본 이미지로 교체하면 돼요.
    · 여기서 분류는 키워드로 흉내 낸 것이고, 실제 앱에서는 AI가 분류하고 서버가 레벨을 올려요.
    · 소품 규칙: 단계 = ⌊레벨 ÷ 5⌋, 개수 = 최대 3, 크기 = 1.0배부터 단계마다 +0.15 (최대 1.6배).
